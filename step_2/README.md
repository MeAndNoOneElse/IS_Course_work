# Описание триггеров
- ## trg_validate_booking_fn()
  При записи и обновлении Booking проверяет, что инвентарь не сломан и не списан, проверяет что нет пересечения на бронь + 20 минут на обслуживание, автоматически переведёт инвентарь в статус booked
  
- ## trg_process_writeoff_fn()
  При записи в WriteOff, ставит статус инвентаря written_off, удаляет его из stocks и удаляет на него все брони

- ## trg_package_add_item_fn()
  При записи в Package, проверяет, что инвентарь действительно числится на этой точке и убирает его от туда.
  При изменении статуса Transfer на delivered весь инвентарь автоматически начинает чиститься на точке - получателе
# Описание функций
- ## get_available_inventory()
  Принимает: ID точки, ID типа инвентаря, размер, время начала и конца брони, буфер на обслуживание (по умолчанию 20 минут). После, ищет исправный инвентарь на точке, исключая позиции, занятые другими бронями в указанный интервал с учетом 20-минутного запаса до и после аренды.
  Возвращает таблицу со списком инвентаря (ID, состояние, износ, цена аренды).
- ## get_available_stock_summary()
  Принимает: ID точки (опционально, NULL для всей сети). Агрегирует количество исправного и свободного инвентаря, группируя результаты по точкам проката, типам инвентаря и доступным размерам.
  Возвращает сводную таблицу (ID и адрес точки, тип, размер, доступное количество).
  
  # Описание процедур
  - ## issue_inventory_for_rent ()
    Принимает: ID клиента, ID инвентаря, ID сотрудника, ID точки, длительность аренды. Проверяет исправность инвентаря и отсутствие чужих броней. Удаляет подтвержденную бронь текущего клиента (если она есть), создает активную запись аренды и меняет статус предмета на rented.

  - ## return_inventory_from_rent ()
    Принимает: ID аренды, флаг повреждения. Переводит аренду в статус completed. Если инвентарь поврежден, меняет его состояние на damaged и статус на in_repair. При возврате целого инвентаря устанавливает статус booked (если есть будущие брони) или available.

  - ## register_inventory_purchase ()
    Принимает: Параметры предмета (тип, размер), данные закупки (цена, поставщик), опционально ID точки и тариф для немедленной постановки на баланс. Создает инвентарь, записывает транзакцию покупки и привязывает предмет к точке в InStock и Pricing. Возвращает сгенерированные ID нового инвентаря и покупки.

# Описание индексов
- ## idx_inventory_type_size_state
  Составной индекс для ускорения поиска доступного инвентаря по типу, размеру и статусу
- ## idx_rent_active_inventory
  Частичный индекс для контроля активных аренд и инвентаря на руках
- ## idx_inventory_needs_repair
   Частичный индекс для мониторинга поломанного инвентаря на точках, ожидающего решения/ремонта
